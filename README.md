## 🎓 HOW IT WORKS

<img src="https://media.giphy.com/media/l46Cy1rHbQ92uuLXa/giphy.gif" width="350"/>

</div>

<br>

3. **AI Prediction** → Match to category
4. **Get Result** → Category + confidence score
